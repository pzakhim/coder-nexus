# Frappe UI Catalog

Guidance for searching, inspecting, and selecting components from the official `frappe-ui` component library.

## When to Use

Activate when specifying or implementing UI features targeting the Frappe framework.

## Core Component Inventory

- **Buttons & Actions**: `Button`, `Dropdown`, `Breadcrumbs`.
- **Forms & Inputs**: `FormControl`, `TextInput`, `Select`, `DatePicker`, `Textarea`, `Checkbox`, `Switch`.
- **Modals & Overlays**: `Dialog`, `Popover`, `Tooltip`.
- **Data Display**: `ListView`, `Avatar`, `Badge`, `Card`, `Tabs`.
- **Icons**: `FeatherIcon`.

Always prioritize these components before writing custom HTML or ad-hoc Tailwind buttons/inputs.
