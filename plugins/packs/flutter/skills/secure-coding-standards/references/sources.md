# Sources & Standards

Security practices in this skill are aligned with international mobile security standards:

1. **OWASP Mobile Application Security (MASVS)**
   - MASVS-STORAGE: Data Storage and Privacy Requirements
   - MASVS-CRYPTO: Cryptography Requirements
   - MASVS-AUTH: Authentication and Session Management
   - MASVS-NETWORK: Network Communication Requirements
   - MASVS-PLATFORM: Platform Interaction Requirements
   - https://mas.owasp.org/MASVS/
2. **Flutter Security Documentation**
   - Best practices for Flutter application security and network configuration.
   - https://docs.flutter.dev/reference/security
3. **iMESPro Security Infrastructure**
   - `app_util`: [ApiService, LocalStorageService, DeviceHelper](../../flutter-core-package-usage/SKILL.md)
