# Sync Workspace Skills

Input: $ARGUMENTS (default: the current workspace; `all` = every registered workspace)

Follow `~/.claude/skill-factory/core/sync-protocol.md`. Provenance format: `~/.claude/skill-factory/core/provenance.md`.

## Workflow

1. **Read the registry:** `~/.claude/skill-factory-registry/*.json` (only the current workspace's file unless `all`). No registry entry for the current workspace → tell the user and offer to run the matching `create-*-skill` in adopt mode.
2. **Status table:** for each workspace × skill, compare the recorded `version` with `~/.claude/skill-factory/generators/<generator>/VERSION`; check the workspace path still exists.

   | Workspace | Skill | Recorded | Latest | Status |
   |---|---|---|---|---|

3. **Ask** which rows to sync (AskUserQuestion; recommend all `behind` rows of the current workspace).
4. **Per workspace, one at a time:** run sync-protocol steps 2–8 — read CHANGELOG entries newer than the recorded version, classify affected spots (project-owned / custom block / clean generated / conflict), show the plan, wait for confirmation, edit, update the registry.
5. **Contribute back** (sync-protocol step 9) only when the user agrees.
6. **Report:** per workspace — files changed, conflicts and how they were resolved, links updated, registry updated, nothing committed.

## Rules

- Never touch custom blocks or project-owned files.
- Never edit a workspace without its own confirmation; never commit unless asked.
- Apply versions in order; a missing CHANGELOG entry is a blocker — report it, do not guess.
- Moving between workspaces needs their folders: use absolute paths; ask the user if a folder needs access.
- Provenance stays in `~/.claude/skill-factory-registry/`, never in a workspace or the Coder Nexus repo.
- A registered workspace that now has `.agents/plugins/coder-nexus/` is managed by Coder Nexus: report it as `managed by Coder Nexus`, do not sync it, and ask whether to drop its registry entry.
